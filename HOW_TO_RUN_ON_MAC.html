How to Run on Mac — Complete Setup Guide

— Prerequisites

What You Need to Install First

Three free tools. Install them once, use them forever. Takes about 10 minutes total.

1

Node.js (v20 or later)

Download the LTS version from nodejs.org.

After installing, open Terminal and verify:

node --version
# Should print v20.x.x or higher
2

pnpm (package manager)

npm install -g pnpm
pnpm --version
# Should print 11.x.x or higher
3

Homebrew + PostgreSQL

First, install Homebrew (Mac's package manager):

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Then add Homebrew to your PATH (required on Apple Silicon Macs):

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Now install and start PostgreSQL:

brew install postgresql@16
brew services start postgresql@16

Create the project database:

createdb resumeredefined
Alternative: Use a free cloud database from Neon.tech or Supabase. Just copy the connection string — no local PostgreSQL needed.

— Download & Install

Get the Project Running

4

Download the project from GitHub

Go to github.com/Sandeep221100/ResumeMac, click the green Code button → Download ZIP.

Extract the ZIP to your Desktop.

5

Open Terminal and navigate to the project

cd ~/Desktop/ResumeMac
6

Install all dependencies

pnpm install

This takes 1–5 minutes. Wait until you see Done.

7

Create the database tables

DATABASE_URL=postgresql://postgres@localhost:5432/resumeredefined pnpm --filter @workspace/db run push

This creates the users and resumes tables in PostgreSQL. Only needed once.

— Start the Servers

Launch Backend + Frontend

You need two Terminal tabs open at the same time. Both must stay open while you use the app.

Terminal Tab 1 — Backend (API Server)

Make sure you're in the project root (~/Desktop/ResumeMac), then run:

PORT=5000 \
JWT_SECRET=my-super-secret-key-change-this-to-anything-long \
DATABASE_URL=postgresql://postgres@localhost:5432/resumeredefined \
pnpm --filter @workspace/api-server run dev

You should see: Server listening {"port":5000}

If you're using a cloud database (Neon, Supabase), replace the DATABASE_URL value with your cloud connection string.

Terminal Tab 2 — Frontend (Web App)

Open a new Terminal tab (⌘ + T), navigate to the project, and run:

cd ~/Desktop/ResumeMac
pnpm --filter @workspace/job-application-master-profile run dev

You should see: Local: http://localhost:5173/

— Your Account

Login & Password

You Create Your Own Account

This is a fresh deployment — there are no pre-made accounts. When you first open the app:

  1. Click "GET STARTED" on the landing page
  2. Click "Sign up" at the bottom of the login form
  3. Enter any email and a password (at least 8 characters)
  4. Click "CREATE ACCOUNT"
  5. You're logged in — your account is saved in the database

Next time you open the app, just log in with the same email and password.

Tip: Your login session lasts 7 days (stored as a secure httpOnly cookie). If you clear browser cookies, you'll need to log in again.

— Troubleshooting

Common Issues

"command not found: brew"

Homebrew is installed but not in your PATH. Run:

eval "$(/opt/homebrew/bin/brew shellenv)"

To make this permanent:

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile

"command not found: pnpm"

npm install -g pnpm

"command not found: createdb"

PostgreSQL tools are not in PATH. Run:

brew install postgresql@16
brew services start postgresql@16
createdb resumeredefined

"DATABASE_URL must be set"

Make sure PostgreSQL is running and you included DATABASE_URL in the backend command.

# Check if PostgreSQL is running:
pg_isready

# If not running:
brew services start postgresql@16

"Port 5000 already in use"

# Find what's using port 5000:
lsof -i :5000

# Or use port 5001 instead:
PORT=5001 JWT_SECRET=... DATABASE_URL=... pnpm --filter @workspace/api-server run dev

"Port 5173 already in use"

pnpm --filter @workspace/job-application-master-profile run dev -- --port 5174

Then open http://localhost:5174 instead.

Blank page in browser

Make sure both Terminal tabs are running (backend AND frontend). The frontend needs the backend for login/signup to work.
